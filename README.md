## ⚠️ Avisos Importantes

* **Status do Projeto:** 🚧 Em desenvolvimento ativo. O motor principal de física e a superclasse de peças estão sendo refatorados.
* **Objetivo Acadêmico:** Este repositório foca na aplicação de conceitos sólidos de Programação Orientada a Objetos (POO), arquitetura de software e inteligência artificial clássica aplicada a jogos de tabuleiro.
* **Branching:** A branch `main` contém apenas código funcional e testado. Funcionalidades incompletas (como o bot de IA ou validações complexas de xeque) estão nas branches de `feature/`.
* **Compatibilidade:** O projeto é desenvolvido e testado nativamente em ambiente Linux (Ubuntu). O terminal deve suportar cores ANSI para a renderização correta da interface textual.
